# HTML 태그 정리

## 1. `<h1>` 태그

제목을 작성할 때 사용하는 태그이다.

```html
<h1>Self Introduction</h1>
```

---

## 2. `<p>` 태그

문단을 작성할 때 사용하는 태그이다.

```html
<p>안녕하세요.</p>
```

---

## 3. `<hr>` 태그

페이지에 가로선을 표시할 때 사용하는 태그이다.

```html
<hr>
```

---

## 4. `<ul>` 태그

순서가 없는 목록을 만들 때 사용하는 태그이다.

```html
<ul>
    <li>HTML</li>
    <li>CSS</li>
</ul>
```

---

## 5. `<ol>` 태그

순서가 있는 목록을 만들 때 사용하는 태그이다.

```html
<ol>
    <li>HTML 공부하기</li>
    <li>CSS 공부하기</li>
</ol>
```

---

## 6. `<li>` 태그

목록의 각 항목을 작성할 때 사용하는 태그이다.

```html
<li>HTML</li>
```

---

## 7. `<img>` 태그

웹페이지에 이미지를 표시할 때 사용하는 태그이다.

```html
<img src="profile.jpg" alt="프로필 이미지">
```

`src`에는 이미지의 경로를 작성한다.

`alt`에는 이미지가 표시되지 않을 때 보여줄 설명을 작성한다.

---

## 8. `<a>` 태그

다른 페이지나 사이트로 이동하는 링크를 만들 때 사용하는 태그이다.

```html
<a href="https://github.com/">GitHub 바로가기</a>
```

`href`에는 이동할 주소를 작성한다.

---

## 9. `<table>` 태그

표를 만들 때 사용하는 태그이다.

```html
<table>
    <tr>
        <td>안주형</td>
        <td>웹 개발</td>
    </tr>
</table>
```

---

## 10. `<thead>` 태그

표에서 제목 영역을 구분할 때 사용한다.

```html
<thead>
    <tr>
        <th>이름</th>
        <th>직무</th>
    </tr>
</thead>
```

---

## 11. `<tbody>` 태그

표에서 실제 데이터가 들어가는 영역을 구분할 때 사용한다.

```html
<tbody>
    <tr>
        <td>안주형</td>
        <td>웹 개발</td>
    </tr>
</tbody>
```

---

## 12. `<tr>` 태그

표에서 하나의 행을 만들 때 사용한다.

```html
<tr>
    <td>안주형</td>
    <td>웹 개발</td>
</tr>
```

---

## 13. `<th>` 태그

표의 제목 셀을 만들 때 사용한다.

```html
<th>이름</th>
```

---

## 14. `<td>` 태그

표의 일반 데이터 셀을 만들 때 사용한다.

```html
<td>안주형</td>
```

---

## 15. `<form>` 태그

사용자에게 데이터를 입력받는 영역을 만들 때 사용한다.

```html
<form>
    <input type="text">
    <button type="submit">전송</button>
</form>
```

---

## 16. `<input>` 태그

사용자가 값을 입력할 수 있는 입력창을 만든다.

```html
<input type="text">
```

---

## 17. `<button>` 태그

사용자가 클릭할 수 있는 버튼을 만든다.

```html
<button type="submit">전송하기</button>
```

---

## 18. `<head>` 태그

HTML 문서의 설정 정보를 작성하는 영역이다.

```html
<head>
    <meta charset="UTF-8">
    <title>나의 이력서</title>
</head>
```

---

## 19. `<body>` 태그

브라우저 화면에 실제로 표시되는 내용을 작성하는 영역이다.

```html
<body>
    <h1>안녕하세요.</h1>
</body>
```
